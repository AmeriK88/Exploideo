2. {% trans "Datos que recopilamos" %}

  • {% trans "Datos de identificación y perfil: nombre, email, nombre de usuario, imagen de perfil, idioma y otra información que decidas completar en tu cuenta." %}
  • {% trans "Datos de cuenta: credenciales de acceso, rol de usuario, configuración básica y preferencias relacionadas con el uso de la plataforma." %}
  • {% trans "Datos de reservas: fechas, número de personas, experiencia reservada, estado de la reserva, facturación y comunicaciones vinculadas a la gestión de la reserva." %}
  • {% trans "Datos de comunicaciones: mensajes enviados a soporte o a otros usuarios dentro de las funcionalidades habilitadas en la plataforma." %}
  • {% trans "Datos de experiencias publicadas por guías: lugar, ciudad, isla, región, descripciones, imágenes, precios, disponibilidad y demás información asociada a la experiencia." %}
  • {% trans "Coordenadas geográficas derivadas automáticamente a partir de la ubicación textual proporcionada para mejorar la búsqueda y navegación dentro de la plataforma." %}
  • {% trans "Datos de geolocalización del dispositivo del usuario cuando este utiliza voluntariamente funciones como 'Near me' y concede permiso a través de su navegador." %}
  • {% trans "Datos técnicos básicos, de seguridad y de funcionamiento necesarios para operar la plataforma, prevenir abusos y diagnosticar incidencias." %}

3. {% trans "Finalidad del tratamiento" %}

  • {% trans "Gestionar tu cuenta, autenticación y perfil dentro de la plataforma." %}
  • {% trans "Permitir la publicación, edición y gestión de experiencias por parte de los guías." %}
  • {% trans "Procesar reservas, cambios, cancelaciones, pagos, facturación y comunicaciones relacionadas con el servicio." %}
  • {% trans "Facilitar la comunicación entre viajeros y guías cuando la funcionalidad esté disponible." %}
  • {% trans "Mostrar experiencias cercanas o relevantes según la ubicación o la zona seleccionada por el usuario." %}
  • {% trans "Resolver automáticamente coordenadas geográficas a partir de ubicaciones textuales para mejorar el descubrimiento de experiencias y funciones como la ordenación por proximidad." %}
  • {% trans "Atender solicitudes, incidencias, soporte técnico y reclamaciones." %}
  • {% trans "Mejorar el funcionamiento, seguridad, fiabilidad y experiencia de uso de la plataforma." %}
  • {% trans "Cumplir obligaciones legales, contables, fiscales o de seguridad que resulten aplicables." %}

4. {% trans "Base legal" %}

{% trans "Tratamos tus datos personales cuando ello es necesario para la ejecución de la relación contractual o precontractual contigo, para el cumplimiento de obligaciones legales aplicables, sobre la base de tu consentimiento cuando sea necesario, y en determinados casos sobre la base de nuestro interés legítimo en mantener la plataforma segura, operativa y correctamente gestionada." %}

{% trans "En el caso de funciones de geolocalización como 'Near me', la ubicación del dispositivo se utiliza únicamente cuando el usuario decide activarla y concede permiso desde su navegador." %}

{% trans "Cuando el tratamiento se base en tu consentimiento, podrás retirarlo en cualquier momento, sin que ello afecte a la licitud del tratamiento realizado con anterioridad a su retirada." %}

5. {% trans "Destinatarios y acceso a los datos" %}

{% trans "No vendemos tus datos personales a terceros." %}

{% trans "Tus datos podrán ser comunicados o accesibles, según corresponda, a:" %}

  • {% trans "Guías o viajeros implicados en una reserva, en la medida necesaria para gestionar la experiencia contratada." %}
  • {% trans "Proveedores tecnológicos que actúan por cuenta de Exploideo, como servicios de alojamiento, correo electrónico, infraestructura, soporte técnico o herramientas necesarias para operar la plataforma." %}
  • {% trans "Proveedores de pago, facturación o prevención de fraude cuando resulte necesario para procesar operaciones económicas o cumplir obligaciones legales." %}
  • {% trans "Proveedores técnicos de localización o geocodificación cuando sea necesario convertir ubicaciones textuales en coordenadas o facilitar funciones de búsqueda por proximidad." %}
  • {% trans "Administraciones públicas, jueces, tribunales o autoridades competentes cuando exista obligación legal." %}

6. {% trans "Transferencias internacionales de datos" %}

{% trans "Con carácter general, procuramos utilizar proveedores ubicados en el Espacio Económico Europeo o que ofrezcan garantías adecuadas conforme a la normativa de protección de datos aplicable." %}

{% trans "No obstante, algunos proveedores técnicos utilizados para operar la plataforma podrían estar ubicados fuera del Espacio Económico Europeo o implicar accesos internacionales a datos. En esos casos, adoptaremos las garantías adecuadas exigidas por la normativa aplicable." %}

{% trans "Si deseas más información sobre las garantías aplicadas en cada caso, puedes solicitarla escribiendo a info@exploideo.com." %}

7. {% trans "Conservación de datos" %}

{% trans "Conservaremos tus datos personales mientras tu cuenta permanezca activa o mientras sean necesarios para prestarte el servicio, gestionar reservas, atender incidencias o cumplir obligaciones legales." %}

{% trans "Los datos de reservas, pagos, facturación y soporte podrán conservarse durante los plazos exigidos por la normativa fiscal, contable, de consumo o por la necesidad de atender posibles responsabilidades." %}

{% trans "Los datos de ubicación asociados a las experiencias de los guías se mantendrán mientras esas experiencias permanezcan activas o mientras resulte necesario para la operativa de la plataforma." %}

{% trans "La ubicación utilizada para funciones como 'Near me' se emplea para mostrar resultados cercanos durante la interacción del usuario y, salvo que se indique expresamente otra cosa, no se almacena de forma permanente en nuestros sistemas." %}
