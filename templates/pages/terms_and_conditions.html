{% trans "Al acceder y usar Exploideo, aceptas estos Términos y Condiciones. Si no estás de acuerdo con ellos, no debes usar la plataforma." %}

{% trans "2. Descripción del servicio" %}

{% trans "Exploideo conecta viajeros con guías locales para facilitar el descubrimiento, solicitud y gestión de reservas de experiencias." %}

{% trans "Exploideo actúa exclusivamente como plataforma tecnológica de intermediación y no presta directamente las experiencias anunciadas, salvo que se indique expresamente lo contrario en el futuro." %}

{% trans "La información publicada sobre cada experiencia es proporcionada por el guía, quien es responsable de su exactitud, legalidad y actualización." %}

{% trans "3. Cuentas de usuario" %}

  • {% trans "Debes proporcionar información veraz, actualizada y completa al registrarte y usar la plataforma." %}
  • {% trans "Eres responsable de mantener la confidencialidad de tu cuenta y contraseña." %}
  • {% trans "No puedes ceder tu cuenta ni permitir un uso fraudulento o no autorizado de la misma." %}
  • {% trans "Los guías deberán completar los procesos de verificación exigidos por Exploideo antes de publicar experiencias, cuando así se solicite." %}

{% trans "Importante:" %} {% trans "La verificación realizada por Exploideo puede incluir comprobaciones básicas de identidad o perfil, pero no sustituye la obligación del guía de contar con las licencias, seguros, permisos y requisitos legales aplicables a su actividad." %}

{% trans "4. Reservas y pagos" %}

  • {% trans "Las reservas o solicitudes de reserva están sujetas a confirmación expresa del guía." %}
  • {% trans "Solicitar una experiencia no implica su confirmación automática." %}
  • {% trans "Los pagos podrán ser gestionados mediante proveedores externos seguros de pago." %}
  • {% trans "El precio total de la experiencia y, en su caso, los impuestos aplicables, se mostrarán antes de finalizar la reserva o en el momento de confirmación." %}
  • {% trans "La factura o justificante, cuando proceda, podrá emitirse conforme a la información facilitada en la reserva y a la normativa aplicable." %}

{% trans "Nota:" %} {% trans "La prestación efectiva de la experiencia corresponde al guía, no a Exploideo." %}

{% trans "5. Cancelaciones, cambios y reembolsos" %}

  • {% trans "El viajero puede cancelar gratuitamente hasta 48 horas antes de la experiencia, salvo que en una experiencia concreta se indique una política distinta de forma clara y previa." %}
  • {% trans "Las solicitudes de cambio de fecha, hora o condiciones están sujetas a aceptación expresa del guía." %}
  • {% trans "Si el guía acepta el cambio, la reserva se actualizará conforme a las nuevas condiciones aplicables." %}
  • {% trans "Si el guía rechaza una solicitud de cambio, el viajero podrá:" %}
    • {% trans "Mantener la reserva original, o" %}
    • {% trans "Cancelar sin penalización cuando así lo prevea la política aplicable en la plataforma." %}
  • {% trans "Si el guía cancela la experiencia o no puede prestarla, el viajero tendrá derecho al reembolso que corresponda según la política aplicable y el estado del pago." %}
  • {% trans "Los reembolsos, cuando procedan, se tramitarán a través del mismo método de pago utilizado, salvo imposibilidad técnica o legal." %}
  • {% trans "Los plazos de abono pueden depender del proveedor de pago o de la entidad bancaria y no siempre dependen exclusivamente de Exploideo." %}

{% trans "Importante:" %} {% trans "Exploideo actúa como intermediario técnico en la gestión operativa de reservas, pagos y reembolsos cuando corresponda, pero no se considera prestador directo de la experiencia." %}

{% trans "6. Responsabilidades" %}

  • {% trans "Guías:" %} {% trans "son responsables de la legalidad de la experiencia, de su correcta ejecución, de la seguridad, de la información facilitada, y de contar con licencias, permisos y seguros cuando sean exigibles." %}
  • {% trans "Viajeros:" %} {% trans "son responsables de facilitar datos correctos, seguir las instrucciones razonables del guía y respetar las normas de seguridad y convivencia." %}
  • {% trans "Plataforma:" %} {% trans "facilita la intermediación tecnológica entre las partes, sin ejecutar directamente la actividad ofrecida por el guía." %}

{% trans "6.1 Actividades al aire libre y asunción de riesgos" %}

  • {% trans "Algunas experiencias pueden desarrollarse al aire libre o implicar actividad física, condiciones meteorológicas variables o riesgos inherentes a la naturaleza de la actividad." %}
  • {% trans "El viajero es responsable de valorar si su estado físico, experiencia o condición personal son adecuados para participar en la actividad." %}
  • {% trans "El guía debe informar de forma clara sobre requisitos, dificultad, material recomendado y condiciones relevantes de seguridad." %}

{% trans "6.2 Transporte y desplazamientos" %}

  • {% trans "Exploideo no presta servicios de transporte, salvo que se indique expresamente en una experiencia concreta." %}
  • {% trans "El viajero es responsable de sus desplazamientos hasta el punto de encuentro o lugar de realización de la experiencia." %}
  • {% trans "El guía no presta transporte de viajeros salvo que cuente con habilitación legal expresa y así se indique claramente en la experiencia." %}

{% trans "6.3 Incidencias y disputas entre usuarios" %}

{% trans "En caso de disputa entre viajero y guía, ambas partes deberán intentar resolverla de buena fe." %}

{% trans "Exploideo podrá intervenir de forma limitada como mediador técnico o gestor de incidencias, pero no asume la posición de parte contractual en la prestación de la experiencia." %}

{% trans "7. Contenido y reseñas" %}

  • {% trans "Las reseñas y valoraciones deben ser honestas, veraces y respetuosas." %}
  • {% trans "No está permitido publicar contenido ofensivo, discriminatorio, ilegal, engañoso o que vulnere derechos de terceros." %}
  • {% trans "Exploideo podrá moderar, ocultar o eliminar contenido cuando considere razonablemente que infringe estos términos o la normativa aplicable." %}

{% trans "8. Limitación de responsabilidad" %}

{% trans "Exploideo no garantiza la disponibilidad ininterrumpida de la plataforma y podrá realizar labores de mantenimiento, actualización o mejora que impliquen interrupciones temporales." %}

{% trans "En la máxima medida permitida por la ley, Exploideo no será responsable de daños indirectos, lucro cesante, pérdida de datos o incidencias derivadas de la actuación del guía, del viajero o de terceros ajenos a su control razonable." %}

{% trans "Cuando legalmente proceda, la responsabilidad máxima de Exploideo se limitará al importe efectivamente pagado a través de la plataforma en relación con la reserva afectada." %}
